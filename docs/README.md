# Jarvis del teléfono

Asistente personal **para tu celular**, independiente de la laptop.

## Qué hace
- Hablar / escribir con Jarvis (Groq)
- Abrir WhatsApp, YouTube, Maps, Gmail, Instagram, TikTok
- Buscar en Google / YouTube
- Cómo llegar (mapas)
- Llamar / SMS (con número)
- Notas locales
- Hora, motivación, chistes

## Cómo usarlo
1. Publica `/docs` en GitHub Pages
2. Abre la URL en el teléfono
3. Toca ⚙ y pega tu Groq API Key
4. “Agregar a pantalla de inicio” para usarlo como app
